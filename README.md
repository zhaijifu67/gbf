# gbf
游戏《碧蓝幻想》辅助工具，用户可自定义配置招式释放流程，纯静态网页
示例网页 [宅爷的GBF工具箱](http://zhaijifu67.github.io/gbf/)


# 本地运行
下载本仓库中的index.html文件到本地即可直接运行。
仓库中的data.js是示例文件，可以不下载。


# 内容编辑

## 表格名称
名称与显示在预览表格中的上方按钮一致即为编辑，没有则新建。

## 角色&召唤石设置
添加角色/召唤石后，进入GBF游戏界面找到需要添加的角色，右键复制角色图像链接到输入框中即可，技能同理。

## 回合编辑
输入内容以每行进行一次解析，解析失败保留原本文字。
**召唤石使用** 输入单个字母（与顶部召唤石设置对应）。
**角色技能** 输入字母+数字，如`A1`表示角色A的1技能，同一角色使用多个技能会自动合并。
**角色技能对目标使用** 如`A1>B`表示角色A对角色B使用1技能。
**FC使用** 直接写`FC`即可匹配
**药物** 使用`BP`进行匹配全队治疗，使用`GP>A`匹配对A角色进行单体治疗


### 分支
可以理解为根据不同特动需要进行不同处理的部分，如极妈的红蓝队伍，可以自定义分支名称。
